## Scope and data model

- 2026-10-06 · Account, invite, password, session and household operations are never AI tools; the tool registry and `/mcp` start in M1. (Confirmed)
- 2026-10-06 · Change records carry a fifth client value, `cli`, for admin commands. (Confirmed)
- 2026-10-06 · Password reset by email ships in M0 when SMTP is configured; without SMTP the admin command is the only path. (Confirmed)
- 2026-10-06 · New domain entities approved at kickoff, each built in its milestone: Favourite and DayTypeOverride (M1), Store and ListTextMemory (M2), StockStatus (M4). (Confirmed)
- 2026-10-06 · Item category is a fixed enum with translation keys, not a table.
- 2026-10-06 · Two invite kinds: `household` (issued by the admin command, creates a new household on acceptance) and `partner` (issued by a member, joins their household).
- 2026-10-06 · Invites are single use, expire after 7 days, and carry both a link token and an 8-character code; both are stored hashed.
- 2026-10-06 · An instance admin is a user with `is_admin`; admin powers exist only in the CLI, there is no admin UI.
- 2026-10-06 · Primary keys are UUIDv7 generated by the app, so clients can create ids for offline use later.
- 2026-10-06 · Language and time zone live on User (as in the brief); visibility toggles, start screen and push switch live on Profile.
- 2026-10-06 · Supported time zones are IANA names; the default is `Europe/Berlin`.
- 2026-10-06 · Any member can rename the household; the name defaults to the first member's name.
- 2026-10-06 · The "open on Today or List" choice is stored on the profile now; its switch appears in M2 together with the list.
- 2026-10-06 · Sessions, login attempts, reset tokens and jobs are infrastructure rows: no change records; they are purged hourly once expired.

## Stack and architecture

- 2026-10-06 · One `compose.yaml` serves local and production; only `.env` differs (`SITE_ADDRESS=http://localhost` locally, a domain in production so Caddy fetches TLS). (Confirmed)
- 2026-10-06 · Docker images come from Docker Hub under their official names; a host that hits Docker Hub rate limits can set a registry mirror in its daemon config.
- 2026-10-06 · Backend uses synchronous SQLAlchemy with psycopg 3; FastAPI runs sync endpoints in its thread pool. Simpler services and tests; async only where streaming needs it (SSE in M2).
- 2026-10-06 · Python 3.13 in the images (brief: 3.12 or newer); dependencies managed with uv.
- 2026-10-06 · Frontend stays on TypeScript 5.9 because typescript-eslint and openapi-typescript do not support TypeScript 7 yet.
- 2026-10-06 · Router: React Router 8 in data mode (`createBrowserRouter`); i18next with react-i18next.
- 2026-10-06 · API client: `openapi-typescript` generates types from the FastAPI schema, `openapi-fetch` calls it; CI fails when the generated file is stale.
- 2026-10-06 · Caddy serves the built frontend and proxies `/api`, `/mcp` and `/events` to the app; the frontend is baked into the Caddy image.
- 2026-10-06 · Migrations run at app start under a Postgres advisory lock; the worker waits for the app to be healthy.
- 2026-10-06 · Job queue: one `job` table, workers claim with `FOR UPDATE SKIP LOCKED`; recurring jobs are declared in code and enqueued by the worker's scheduler loop.
- 2026-10-06 · Files are stored on the `files` volume behind a `Storage` interface (local disk implementation only).
- 2026-10-06 · Dockerfiles accept an optional `build_ca` build secret for builds behind TLS-intercepting proxies; normal builds ignore it.
- 2026-10-06 · Playwright is pinned to 1.56.1 to match the Chromium build available in the development sandbox; CI installs the matching browser.
- 2026-10-06 · No ACME email in the Caddyfile: Let's Encrypt no longer sends expiry mail and Caddy renews by itself.

## Security

- 2026-10-06 · Session cookie `mahlzeit_session`: random 32-byte token, stored as SHA-256 hash, HttpOnly, SameSite=Lax, Secure when `BASE_URL` is https, 30-day sliding expiry.
- 2026-10-06 · CSRF: every unsafe request must send header `X-CSRF-Token` equal to the session's token (returned by `/api/auth/me`); login and invite acceptance are protected by SameSite plus an Origin check.
- 2026-10-06 · Login rate limit: 5 failures per email and 20 per IP in 15 minutes, counted in Postgres.
- 2026-10-06 · Passwords: Argon2id with argon2-cffi defaults, minimum 10 characters, no other composition rules.
- 2026-10-06 · Secrets at rest (push subscription keys now, API keys later) use AES-256-GCM with `ENCRYPTION_KEY` from the environment.
- 2026-10-06 · The API returns error codes (`{"code": "...", "detail": ...}`), never user-facing prose; the client translates them.
- 2026-10-06 · Password reset tokens are single use, valid for 1 hour, stored hashed; using one ends all of that user's sessions. At most 3 requests per user per hour.
- 2026-10-06 · Changing the password ends all other sessions of that user and keeps the current one.
- 2026-10-06 · In production the app and worker refuse to start when `ENCRYPTION_KEY`, `BASE_URL`, VAPID or SMTP settings are missing or inconsistent.

## PWA, push and i18n

- 2026-10-06 · Service worker built with vite-plugin-pwa (`injectManifest`), precaching the app shell; push and notification-click handlers live in the same worker.
- 2026-10-06 · The web manifest uses relative URLs, so `BASE_URL` only needs to reach the server-side parts (emails, push, connector metadata).
- 2026-10-06 · Push messages are sent from the worker through the job queue; subscriptions answering 404 or 410 are deleted.
- 2026-10-06 · A push subscription belongs to whoever last signed in on that browser; at most 10 devices per user, oldest dropped.
- 2026-10-06 · Offline, the app shows the last signed-in user from localStorage (without the CSRF token) until the server answers; signing out or a 401 clears it.
- 2026-10-06 · Caddy sends `no-cache` for everything except hashed `/assets/*` (immutable, 1 year), so updates arrive on the next open.
- 2026-10-06 · Language default for a new user is the inviter's language, else German; the login screen follows the browser language until someone logs in.
- 2026-10-06 · Hard-coded UI strings are blocked by `eslint-plugin-i18next`; a unit test requires identical key sets in de, en and nl.

## Operations

- 2026-10-06 · Backups: `pg_dump` custom format plus a tarball of the files volume, encrypted with `age` to `BACKUP_AGE_RECIPIENT`; run by a `backup` service under the `ops` Compose profile; 14 most recent kept.
- 2026-10-06 · Without `BACKUP_AGE_RECIPIENT` the backup is written unencrypted and the script warns; copying backups off the machine is left to the operator.
- 2026-10-06 · Local M0 verification treats `http://localhost` as the live URL; phone installation is verified after deployment because Android requires HTTPS.
- 2026-10-06 · Installability is checked with Chrome's own `Page.getInstallabilityErrors` in a persistent profile, because Chrome never offers install in incognito contexts.
- 2026-10-06 · `scripts/restore-drill.sh` runs as a separate Compose project (`mahlzeit-drill`, port 8088) with its own volumes, backup directory and throwaway age key, so it can never touch real data. `BACKUP_DIR` is configurable for that reason.
